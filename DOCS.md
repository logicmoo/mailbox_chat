# Documentation

All documentation lives in
[`src/mailbox_channels/resources`](src/mailbox_channels/resources) so it is
packaged with the wheel and served by a running relay at `/<name>.md`.

- [INSTRUCTIONS.md](src/mailbox_channels/resources/INSTRUCTIONS.md) — operational
  contract, address scheme, platform setup, and the CLI/REST reference.
- [INSTALL_WITH_CODEX.md](src/mailbox_channels/resources/INSTALL_WITH_CODEX.md) —
  paste-into-Codex prompt to install the client into a workspace.
- [AUTOMATION_PROMPT.md](src/mailbox_channels/resources/AUTOMATION_PROMPT.md) —
  recurring Codex automation prompt, agent naming, and command reference.
- [WORKBENCH_CODEX_WORKER.md](src/mailbox_channels/resources/WORKBENCH_CODEX_WORKER.md) —
  workbench Codex worker guide.
- [DESIGN_MULTI_NETWORK.md](src/mailbox_channels/resources/DESIGN_MULTI_NETWORK.md) —
  multi-network identity, agents, routing, and lifecycle design.
